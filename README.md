# نظام إدارة مؤسسة صخر المصري (الأردن - عمّان) — نسخة السيرفر المحلي القابلة للتعديل

تطبيق ويب متكامل لإدارة حضور وانصراف الموظفين عبر الهاتف، شؤون الموظفين، المسحوبات النقدية اليومية، حساب الرواتب، ومصروفات الفروع بالدينار الأردني (`د.أ`).

---

## 💻 اولاً: طريقة تشغيل المشروع على سيرفر محلي (Local Server)

يحتوي هذا المجلد على طريقتين للتشغيل على السيرفر المحلي لديك:

### الطريقة الأولى (الأسهل والأفضل للتعديل): عبر Node.js (بنقرة زر على ويندوز)
1. قم بتحميل وتثبيت برنامج **Node.js** (النسخة LTS) من الموقع الرسمي: `https://nodejs.org`
2. فك ضغط ملف المشروع `sakhr-almasri-project.zip` في أي مجلد على جهاز السيرفر المحلي لديك.
3. اضغط مرتين على ملف **`start-local-server.bat`** الموجود داخل المجلد.
4. سيقوم الملف تلقائياً بتثبيت الحزم وتشغيل السيرفر المحلي على المنفذ `3000`:
   - على نفس جهاز الكمبيوتر: افتح المتصفح على الرابط `http://localhost:3000`
   - **للدخول من هواتف الموظفين في الفرع**: سيظهر لك في شاشة التشغيل رقم الـ IP المحلي لجهازك (مثلاً `http://192.168.1.15:3000`)؛ أي موظف متصل بنفس شبكة الواي فاي في الفرع يفتح هذا الرابط من هاتفه ليسجل حضوره وانصرافه وتُحفظ البيانات مباشرة على جهاز السيرفر!

### الطريقة الثانية: عبر XAMPP أو WAMP أو أي استضافة ويب جاهزة
- يوجد داخل الملف المضغوط مجلد باسم **`dist`** يحتوي على النسخة الجاهزة للعرض المباشر؛ يمكنك نقل محتوياته إلى مجلد `htdocs` في برنامج XAMPP أو WAMP ليعمل مباشرة.

## ✏️ ثانياً: كيف تقوم بتعديل الكود والتصميم؟

جميع ملفات المشروع مفتوحة المصدر وقابلة للتعديل الكامل باستخدام برنامج **Visual Studio Code (VS Code)**:

- **`src/seedData.ts`**: لتعديل الفروع الافتراضية، أسماء الموظفين الأولية، أو الإعدادات الافتراضية.
- **`src/App.tsx`**: لتعديل الشريط العلوي، اسم المؤسسة، القوائم، وإعدادات كلمة المرور.
- **`src/components/HomePage.tsx`**: لتعديل الصفحة الرئيسية (بوابة دوام الموظفين + تسجيل دخول الإدارة).
- **`src/components/AttendancePage.tsx`**: لتعديل صفحة سجل الدوام وطرق التحقق (GPS / QR / PIN).
- **`src/components/EmployeesPage.tsx`**: لتعديل صفحة شؤون الموظفين وإدارة الفروع.
- **`src/components/WithdrawalsPage.tsx`**: لتعديل صفحة المسحوبات النقدية وسندات الصرف.
- **`src/components/PayrollPage.tsx`**: لتعديل صفحة الرواتب ومعادلة حساب الصافي.
- **`src/components/ExpensesPage.tsx`**: لتعديل صفحة مصروفات الفروع اليومية.
- **`server.ts`**: ملف السيرفر المحلي المسؤول عن حفظ كل التغييرات داخل قاعدة البيانات المحلية `data/database.json`.
